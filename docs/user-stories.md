# حالات الاستخدام وقصص المستخدمين لموقع معرض سيارات (السعودية) — جديد + مستعمل

هذه الوثيقة تُحوّل نطاق الـ **MVP** إلى متطلبات عملية قابلة للتحويل لاحقًا إلى مهام تنفيذ **Backlog**. نستخدم هنا مستويين من التحديد:

- **حالة الاستخدام (Use Case):** سيناريو كامل (هدف + خطوات + نتيجة متوقعة).
- **قصة المستخدم (User Story):** جملة مختصرة لاحتياج المستخدم مع شروط قبول واضحة.

---

## 1) فئات المستخدمين

### 1. الزائر/العميل
- يبحث عن سيارة جديدة أو مستعملة.
- يريد معلومات واضحة وسريعة.
- يريد خطوة عملية مباشرة: تواصل أو حجز.

### 2. موظف المبيعات/خدمة العملاء
- يستقبل طلبات العملاء بشكل منظم.
- يتابع الطلبات ويرد عليها.
- يحتاج فرز وتتبع حالة كل طلب.

### 3. مدير الموقع/الإدارة
- يدير محتوى السيارات والموقع: إضافة/تعديل/إخفاء.
- يرفع الصور ويحدث بيانات الفروع والتواصل.
- يدير المستخدمين والصلاحيات (بحسب الحاجة).

---

## 2) حالات الاستخدام الأساسية

**الهدف العام:** عرض السيارات بوضوح + تحويل الزائر إلى حجز/تواصل + إدارة سهلة للمحتوى والطلبات.

### حالة الاستخدام 1: استعراض الصفحة الرئيسية
- **المستخدم:** عميل/زائر  
- **الهدف:** فهم سريع لما يقدمه المعرض والوصول إلى (جديد/مستعمل) أو التواصل  
- **المدخلات/الشروط:** الموقع يعمل + بيانات أساسية للشركة + روابط (جديد/مستعمل)  
- **الخطوات الأساسية:** فتح الرئيسية → مشاهدة تعريف مختصر → الانتقال إلى جديد/مستعمل أو صفحة التواصل  
- **النتيجة المتوقعة:** وصول سريع لمسار واضح (جديد/مستعمل/تواصل)

### حالة الاستخدام 2: تصفح السيارات الجديدة
- **المستخدم:** عميل  
- **الهدف:** استعراض السيارات الجديدة المتاحة ثم الانتقال إلى سيارة محددة  
- **المدخلات/الشروط:** وجود سيارات جديدة منشورة + صور/بيانات أساسية مكتملة + فرز اختياري (Filter)  
- **الخطوات الأساسية:** فتح صفحة السيارات الجديدة → فرز اختياري → اختيار سيارة → فتح صفحة التفاصيل  
- **النتيجة المتوقعة:** قائمة مرتبة تساعد على الوصول بسهولة إلى تفاصيل سيارة جديدة

### حالة الاستخدام 3: تصفح السيارات المستعملة
- **المستخدم:** عميل  
- **الهدف:** استعراض السيارات المستعملة مع معلومات واضحة (السعر/الممشى/السنة) ثم اختيار سيارة مناسبة  
- **المدخلات/الشروط:** وجود سيارات مستعملة منشورة + حقول (السعر/الممشى/السنة) متاحة + صور  
- **الخطوات الأساسية:** فتح صفحة السيارات المستعملة → تصفح القائمة → اختيار سيارة → فتح صفحة التفاصيل  
- **النتيجة المتوقعة:** قائمة مرتبة تساعد على الوصول بسهولة إلى تفاصيل سيارة مستعملة

### حالة الاستخدام 4: البحث والتصفية (فلترة)
- **المستخدم:** عميل  
- **الهدف:** تضييق النتائج عبر فلاتر مثل السعر أو السنة أو الماركة أو المدينة  
- **المدخلات/الشروط:** توفر فلاتر/حقول قابلة للتصفية + نتائج قابلة للتحديث بدون تعقيد  
- **الخطوات الأساسية:** فتح صفحة القائمة (جديد/مستعمل) → اختيار فلاتر/نطاقات → تطبيق الفلاتر → عرض النتائج المحدثة  
- **النتيجة المتوقعة:** نتائج أقل وأكثر صلة بدون تعقيد

### حالة الاستخدام 5: عرض تفاصيل سيارة
- **المستخدم:** عميل  
- **الهدف:** رؤية الصور والمواصفات والمعلومات الأساسية لتحديد مدى مناسبة السيارة  
- **المدخلات/الشروط:** سيارة منشورة + صفحة تفاصيل تحتوي صور + مواصفات + أزرار CTA (حجز/تواصل)  
- **الخطوات الأساسية:** من القائمة/البحث → فتح صفحة التفاصيل → استعراض الصور والمواصفات → اختيار (حجز/تواصل)  
- **النتيجة المتوقعة:** صفحة واضحة تحسم قرار العميل: تواصل/حجز أو مغادرة

### حالة الاستخدام 6: حجز تجربة قيادة لسيارة جديدة
- **المستخدم:** عميل  
- **الهدف:** حجز تجربة قيادة بسرعة عبر نموذج بسيط  
- **المدخلات/الشروط:** سيارة جديدة متاحة + نموذج حجز (الاسم/الجوال/المدينة/موعد مقترح) + إشعار نجاح  
- **الخطوات الأساسية:** فتح تفاصيل السيارة → الضغط على حجز تجربة قيادة → تعبئة النموذج → إرسال الطلب → رسالة تأكيد  
- **النتيجة المتوقعة:** إنشاء طلب تجربة قيادة يصل للشركة مع بيانات العميل

### حالة الاستخدام 7: حجز موعد معاينة لسيارة مستعملة
- **المستخدم:** عميل  
- **الهدف:** حجز موعد لمعاينة السيارة أو زيارتها في الفرع  
- **المدخلات/الشروط:** سيارة مستعملة متاحة + اختيار فرع/مدينة + نموذج موعد (تاريخ/وقت)  
- **الخطوات الأساسية:** فتح تفاصيل السيارة → الضغط على حجز معاينة → تحديد الموعد/الفرع → إرسال الطلب → رسالة تأكيد  
- **النتيجة المتوقعة:** إنشاء طلب معاينة (Viewing Appointment)

### حالة الاستخدام 8: تواصل عام مع الشركة
- **المستخدم:** عميل  
- **الهدف:** إرسال استفسار عام لا يتطلب حجزًا  
- **المدخلات/الشروط:** صفحة تواصل + نموذج رسالة + حقول أساسية (الاسم/الجوال/الموضوع/الرسالة)  
- **الخطوات الأساسية:** فتح صفحة تواصل معنا → تعبئة النموذج → إرسال → تأكيد الاستلام  
- **النتيجة المتوقعة:** وصول الرسالة إلى لوحة الإدارة بشكل منظم

### حالة الاستخدام 9: تسجيل الدخول للموظفين/الإدارة
- **المستخدم:** موظف مبيعات / مدير موقع  
- **الهدف:** الدخول للوصول إلى لوحة الإدارة وإدارة المحتوى والطلبات  
- **المدخلات/الشروط:** حسابات موظفين مفعّلة + أدوار/صلاحيات + صفحة تسجيل دخول آمنة  
- **الخطوات الأساسية:** فتح صفحة الدخول → إدخال البيانات → التحقق → الانتقال للوحة الإدارة حسب الصلاحية  
- **النتيجة المتوقعة:** صلاحيات واضحة حسب الدور ومنع الوصول غير المصرح

### حالة الاستخدام 10: إدارة السيارات (إضافة/تعديل/إخفاء)
- **المستخدم:** مدير موقع  
- **الهدف:** إضافة سيارات جديدة/مستعملة وتحديث بياناتها ورفع صورها وتحديد التوفر  
- **المدخلات/الشروط:** صلاحية مدير + نموذج سيارة (حقول أساسية + صور) + حالة نشر/إخفاء  
- **الخطوات الأساسية:** الدخول للوحة الإدارة → إضافة/تعديل سيارة → رفع الصور → حفظ → نشر/إخفاء  
- **النتيجة المتوقعة:** تحديث المحتوى دون تدخل مطور

### حالة الاستخدام 11: متابعة طلبات العملاء
- **المستخدم:** موظف مبيعات  
- **الهدف:** رؤية طلبات (تجربة قيادة/معاينة/تواصل) وفرزها حسب الحالة (جديد/تم التواصل/مغلق)  
- **المدخلات/الشروط:** وجود طلبات محفوظة + حالات للطلب + صلاحية وصول لفريق المبيعات  
- **الخطوات الأساسية:** الدخول للوحة الإدارة → فتح قائمة الطلبات → فرز/بحث → فتح طلب → تحديث الحالة/إضافة ملاحظة  
- **النتيجة المتوقعة:** عدم ضياع الطلبات وتحسين سرعة الاستجابة

## 3) قصص المستخدمين (User Stories) + شروط القبول

### 3.1 قصص العميل (واجهة الموقع)

#### قصة المستخدم 1: دخول سريع
كـ زائر أريد أن أرى في الصفحة الرئيسية خيارين واضحين (جديد/مستعمل) ووسائل تواصل بارزة، لكي أحدد مساري خلال ثوانٍ.

#### قصة المستخدم 2: تصفح السيارات الجديدة
بصفتي عميلًا، أريد مشاهدة قائمة السيارات الجديدة، حتى أختار موديلًا مناسبًا.

**شروط القبول:**
- تظهر القائمة مرتبة وواضحة.
- يمكن فتح صفحة التفاصيل لكل سيارة من القائمة.

#### قصة المستخدم 3: تصفح السيارات المستعملة مع معلومات أساسية
بصفتي عميلًا، أريد مشاهدة قائمة السيارات المستعملة مع معلومات أساسية، حتى أقارن بسرعة.

**شروط القبول:**
- كل بطاقة سيارة تعرض على الأقل: (السعر، الممشى، السنة، المدينة/الفرع، صورة واحدة على الأقل).
- يمكن فتح صفحة التفاصيل لكل سيارة.

#### قصة المستخدم 4: فلترة النتائج
بصفتي عميلًا، أريد فلترة السيارات حسب معايير أساسية، حتى أصل لنتائج مناسبة بسرعة.

**شروط القبول:**
- توجد 3 فلاتر على الأقل تعمل وتؤثر على النتائج (مثل: السعر/السنة/المدينة أو الماركة).
- عند تغيير الفلاتر تتحدث النتائج بشكل صحيح.

#### قصة المستخدم 5: صفحة تفاصيل سيارة واضحة
بصفتي عميلًا، أريد صفحة تفاصيل واضحة لسيارة محددة، حتى أتخذ قرار التواصل أو الحجز.

**شروط القبول:**
- معرض صور للسيارة.
- معلومات أساسية واضحة بحسب نوع السيارة (جديد/مستعمل).
- زر خطوة تالية واضح (حجز/تواصل) ضمن الصفحة.

#### قصة المستخدم 6: حجز تجربة قيادة (للسيارات الجديدة)
بصفتي عميلًا، أريد حجز تجربة قيادة لسيارة جديدة، حتى أجربها قبل قرار الشراء.

**شروط القبول:**
- نموذج حجز بسيط يحتوي بيانات أساسية (اسم/جوال على الأقل).
- يظهر للعميل تأكيد باستلام الطلب بعد الإرسال.
- يتم حفظ الطلب ليظهر في لوحة الإدارة للمتابعة.

#### قصة المستخدم 7: حجز موعد معاينة (للسيارات المستعملة)
بصفتي عميلًا، أريد حجز موعد لمعاينة سيارة مستعملة، حتى أزورها في وقت مناسب.

**شروط القبول:**
- اختيار تاريخ/وقت (أو على الأقل “وقت مفضل” إن لم نعتمد جدولًا كاملًا).
- يظهر تأكيد باستلام الطلب بعد الإرسال.
- يتم حفظ الطلب ليظهر في لوحة الإدارة للمتابعة.

#### قصة المستخدم 8: التواصل العام
بصفتي عميلًا، أريد إرسال رسالة للشركة، حتى أسأل عن استفسار عام.

**شروط القبول:**
- نموذج تواصل يحتوي حقولًا أساسية (الاسم/الجوال/الرسالة).
- منع إرسال الرسائل الفارغة.
- حفظ الرسالة لتظهر في لوحة الإدارة للمتابعة.

---

### 3.2 قصص الإدارة والموظفين (لوحة الإدارة + الحسابات)

#### قصة المستخدم 9: تسجيل الدخول
بصفتي موظفًا، أريد تسجيل الدخول، حتى أتمكن من إدارة الطلبات والمحتوى.

**شروط القبول:**
- صفحة تسجيل دخول تعمل.
- منع الوصول للوحة الإدارة بدون صلاحية.

#### قصة المستخدم 10: إضافة سيارة
بصفتي مدير موقع، أريد إضافة سيارة جديدة/مستعملة، حتى تظهر في الموقع.

**شروط القبول:**
- يمكن حفظ السيارة بنجاح.
- تظهر السيارة ضمن قائمة السيارات في الموقع بعد النشر.
- يمكن إخفاء السيارة (غير متاحة) دون حذفها.

#### قصة المستخدم 11: إدارة صور السيارة
بصفتي مدير موقع، أريد رفع صور متعددة لكل سيارة، حتى يراها العميل بوضوح.

**شروط القبول:**
- رفع عدة صور للسيارة وتظهر في معرض الصور بصفحة التفاصيل.
- إمكانية تحديد صورة رئيسية تظهر في بطاقة السيارة داخل القوائم.

#### قصة المستخدم 12: تحديث حالة السيارة
بصفتي مدير موقع، أريد تغيير حالة السيارة (متاحة/غير متاحة/محجوزة)، حتى لا يظهر محتوى غير صحيح.

**شروط القبول:**
- تغيير الحالة محفوظ.
- الحالة تنعكس على عرض السيارة في الموقع (إظهار/إخفاء أو تمييز حسب السياسة المعتمدة).

#### قصة المستخدم 13: متابعة الطلبات
بصفتي موظف مبيعات، أريد رؤية الطلبات الواردة وتصنيفها، حتى لا تضيع أي فرصة.

**شروط القبول:**
- قائمة تعرض جميع الطلبات (تجربة قيادة/معاينة/تواصل).
- لكل طلب حالة واضحة (جديد/تم التواصل/مغلق).
- إمكانية إضافة ملاحظة داخلية على الطلب.
